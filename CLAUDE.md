# Claude Code Session Prompt

## Стартовый промт для сессии

Контекст проекта: лендинг на React + Vite, чистый CSS с CSS-переменными, тёмная тема, анимации GSAP + Framer Motion, i18n (en/ru). Дизайн-система кратна 5. Верстаю блок за блоком.

## Правила на эту сессию

1. Сначала изучи текущее состояние проекта (структуру папок, /src/styles/tokens.css, уже свёрстанные секции), потом действуй. Не предполагай — проверяй файлы.
2. Используй ТОЛЬКО существующие дизайн-токены и семантические переменные. Не выдумывай цвета, отступы, размеры. Если нужного токена нет — спроси, не изобретай.
3. Все значения кратны 5. Никаких произвольных px.
4. Бери данные (контент, токены) из Figma через MCP, а не из головы.
5. Работай ровно над тем, что я прошу — один блок/задача за раз. Не верстай и не трогай другие секции без явной просьбы.
6. Если чего-то не хватает или есть неоднозначность — задай вопрос, прежде чем писать код.
7. Не рефакторь существующий код без моего разрешения.
