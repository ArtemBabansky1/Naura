# Claude Code Session Prompt

## Стартовый промт для сессии

Контекст проекта: лендинг на React + Vite, чистый CSS с CSS-переменными, тёмная тема, анимации GSAP + Framer Motion, i18n (en/ru). Дизайн-система кратна 5. Верстаю блок за блоком.

## Правила на эту сессию

1. Сначала изучи текущее состояние проекта (структуру папок, /src/styles/tokens.css, уже свёрстанные секции), потом действуй. Не предполагай — проверяй файлы.
2. Используй ТОЛЬКО существующие дизайн-токены и семантические переменные. Не выдумывай цвета, отступы, размеры. Если нужного токена нет — спроси, не изобретай.
3. Все значения кратны 5. Никаких произвольных px.
4. Бери данные (контент, токены) из Figma через MCP, а не из головы.
5. Работай ровно над тем, что я прошу — один блок/задача за раз. Не верстай и не трогай другие секции без явной просьбы.
6. Если чего-то не хватает или есть неоднозначность — задай вопрос, прежде чем писать код.
7. Не рефакторь существующий код без моего разрешения.
8. Типографика: в текстах локалей (en и ru) не оставляй висячих предлогов и союзов — приклеивай их к следующему слову неразрывным пробелом. Подробности ниже.

## Типографика (висячие предлоги)

Короткие предлоги и союзы не должны оставаться в конце строки — между ними и следующим словом ставится неразрывный пробел. В JSON он записывается видимым escape ` ` (например `в Telegram`, `Get a demo`), который i18next/JSON.parse превращают в U+00A0.

- **Автоматизация:** после правки или добавления текстов в локалях прогоняй `npm run typography` (или `node scripts/typography.mjs`). Скрипт идемпотентен — повторный запуск ничего не ломает; `--check` показывает количество склеек без записи.
- **Списки слов** (русские предлоги/союзы 1–3 буквы, английские артикли/предлоги/союзы) лежат в [scripts/typography.mjs](scripts/typography.mjs) — правь их там, если нужно расширить.
- **Что НЕ трогаем:** ссылки, почты, @-хендлы, плейсхолдеры `{{...}}`, теги `<...>`, код. Скрипт их не задевает, и вручную тоже не приклеивай предлоги внутри технических строк.
- При ручном добавлении новой копирайт-строки проще дописать обычные пробелы и затем один раз прогнать скрипт, чем расставлять ` ` руками.
